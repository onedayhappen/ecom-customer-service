# 04 判断消息归属并处理不明确的回答

把消息关联到正确事项；无法确定时提出能区分对象的问题。本次只保存决定与进度，不执行退款等操作。

前置：完成 [03 找出可能相关的事项](03-task-candidates.md)。 总体约束见 [完整方案](../AGENT_REFACTOR_PLAN.md)。

## 改动位置

`app/tasks/routing.py`、`app/tasks/service.py`、`app/agents`、`app/prompts`、`app/api/conversation.py`。

## 实施步骤

1. 在单 Agent 中增加结构化归属判断。输入为 02 的消息范围和 03 的候选；输出为来源消息、目标事项或新建请求、消息作用、拟修改字段、关联依据和待澄清问题。
2. 用 Pydantic 限定输出结构；关联依据只保留可核验的原话或工具引用，不保存隐藏推理。一次输入可产生多个决定，不强制每条消息只有一个意图。
3. 程序核验用户归属、明确订单和商品、待答问题、事项版本、接管状态以及已有操作。拒绝虚构事项编号、越权对象、已失效问题和没有来源的字段修改。
4. 明确唯一时更新事项；故障排查变为退款可以修改原目标；独立的新目标创建新事项。问候无需创建事项，待澄清问题的回答不自动视为新的业务请求。
5. 多个候选都合理时保存原话和待澄清记录，不修改候选业务字段。优先只读核实，仍不明确时只问一个区分问题；“是的”不能直接作为多个操作的共同确认。
6. 同一会话按顺序保存关联结果，用消息与决定的稳定编号去重。提交时检查已读取范围和版本，冲突后重新读取，限定重试次数；反复无法确定时保留问题或交人工。

## 验收

- “耳机退款，鞋子查物流”产生两个事项；“左耳没声音”补到对应待答问题。
- “是的”面对两道有效问题时澄清；明确的订单选择可以直接关联。
- 历史事项续接不重复新建，语义相似但目标不同的事项不被强行合并。
- 固定模型输出验证越权、格式、版本和去重规则；用脱敏真实模型样例检查关联和澄清质量，记录误关联及不必要澄清。

## 本次交付边界

交付可回放的关联决定和事项更新。05 根据这些来源记录处理关联错误。

## 已实现接口

- `AgentEngine.associate(context)` 使用同一 Agent 的模型客户端输出结构化建议；建议只能新建、补充或调整事项、请求澄清、忽略无关消息，不直接调用业务工具。
- `AssociationService(store, authenticated_user_id).process(batch, engine)` 读取候选、调用模型、校验并提交。最多尝试两次，第二次可通过只读订单工具补充依据；仍不可靠时保存一个待澄清问题，不写入猜测的业务字段。
- `snapshot` / `commit` 分开提供，便于固定输出测试与回放。提交检查完整消息范围、原话引用、事项权限和版本、问题是否已发布、人工接管及业务操作状态。一条消息可以产生多个决定，同一事项的补充按消息顺序合并。
- 判断依据可引用公开客服问题；新增字段必须引用用户原话，不能把客服说法当成用户提供的事实。订单编号不能冒充数量；序号回答必须对应仍有效的选项。存在多道有效问题时，“是的”不能直接选择其中一道。
- 事项更新、关联决定、来源索引和消息处理位置在同一事务提交。相同作业重试返回原回执，租约过期的执行者不能覆盖进度。新消息会进入下一次归属处理，不被旧批次提前确认。
- `association_clarifications` 保存问题、候选版本和原始消息。第 08 部分发布时需携带 `clarification_id`、`clarification_version`；用户明确选择后，将此前原话和本次回答一起关联。未发送或过期的问题不能接收简短确认。
- 暂停和恢复保留尚待处理的信息，但原问题的版本不再有效。取消和完成回答会清除本次等待；恢复历史事项不恢复旧授权。
- `associate_pending_messages` 是受控内部入口，新链路仍默认关闭。第 05 部分可通过 `association_decisions`、`association_sources` 和事项变更记录追查、纠正归属。

验证入口为 `tests/test_message_association.py`。真实模型小样本入口为 `python -m scripts.eval_association --live`，只使用合成电商资料和隔离临时数据库，不调用真实业务写入。2026-10-20 使用当前配置的 `deepseek-v4-flash` 验证 9 个场景，9 个通过、误关联 0 次、不必要澄清 0 次；这不是生产准确率估计。完整结构化结果写入被 Git 忽略的 `data/evaluation/association_smoke.json`，不保存隐藏推理。
