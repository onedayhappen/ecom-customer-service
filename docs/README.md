## 关键术语

| 术语     | 含义                                         |
| -------- | -------------------------------------------- |
| 会话     | 消息容器，一个会话可以包含多个事项           |
| 消息批次 | 一次领取并固定范围的用户输入，不等于一个事项 |
| 事项     | 用户希望推进的目标，可以跨会话续接           |
| 执行     | 对某个事项运行一次受版本和预算约束的处理     |
| 业务操作 | 固定对象与参数的办理，通过用户确认后提交     |
| 回执     | 真实查询、提交或外部处理的结果记录           |
| 允许结论 | 从有效证据投影、可由服务端渲染的答复内容     |

## 文档与源码的对应方式

每篇文档在“代码入口”中链接模块实现。接口名称、字段和规则以当前契约与迁移文件为准；文档中的流程描述不替代实际配置、数据或外部渠道接入。

客服事项状态、订单状态、售后阶段和资金渠道状态分别表示不同事实。学习时结合对应模块的数据模型阅读，避免把接收成功、申请提交或模型执行完成当作业务结果。
