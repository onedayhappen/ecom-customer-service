# 会员权益

## 会员身份

平台成长会员、平台VIP和店铺会员是三种独立身份，可以同时拥有。年卡、月卡表示VIP订阅期限，不是成长等级。未开通VIP的用户也可以拥有成长等级。

## 平台成长等级

| 等级 | 成长值门槛 |
|---|---:|
| 青铜 | 0 |
| 白银 | 1,000 |
| 黄金 | 3,000 |
| 铂金 | 8,000 |
| 钻石 | 20,000 |
| 黑钻 | 50,000 |

以上为本项目配置，不是淘宝淘气值门槛。新注册用户默认加入已配置的青铜成长体系。成长值与可消费积分分开，兑换积分不意味着降低成长等级。当前演示用户的等级为模拟授予，不代表已经根据订单自动计算。

设计采用过去365天成长值、每季度重评；自动成长入账和季度重评尚未启用。当前等级及有效期以会员工具返回为准，不能根据订单金额自行推断或承诺自动升级。

## VIP月卡与年卡

有效VIP身份以订阅起止时间、会员状态为准。月卡、年卡共享VIP身份，套餐期限分别保存；到期后不再享有需要有效VIP的权益。当前演示数据没有实际收费，也没有自动续费。用户是否开通、卡种和到期时间必须查询本人记录。

VIP状态包括有效、未开通、尚未生效、已到期、暂停或无法核实。数据库存在订阅记录不等于现在是有效VIP；无法核实时应说明原因。

## 店铺会员

每个店铺独立维护普通或高级会员关系，只对对应店铺生效。平台VIP不自动获得所有店铺会员身份。具体店铺身份及有效期以查询结果为准。

## 会员优惠券

成长等级和VIP月度券已开放领取，具体活动及本人剩余额度须查询工具。成长券均满200使用，青铜/白银/黄金/铂金/钻石/黑钻分别减10/15/20/25/30/40元，每月额度分别为1/1/2/2/3/3张。VIP每月额外满200减50两张、满500减100一张，月卡与年卡共享该额度。

额度不是已领取的优惠券。领取时检查当前会员身份、活动时间、总量及本人同月已领次数；更换模板、升级或月卡改年卡不清零已领次数。成长券领取后按冻结规则使用；VIP券使用时也必须有有效VIP订阅。到期、暂停或订阅无法唯一核实时不能领取或使用VIP券。

周期按北京时间自然月计算，券到期不晚于活动期限、本月末及领取时会员有效期。当前活动为2026年10月，不能承诺下月自动发券或自动续期。

已领取优惠券继续按其领取快照执行。用户询问现有券时查询优惠券记录；不要仅凭会员等级推断其持有某张券。运费险、积分倍率、生日礼包和专属客服等尚未接通的服务不作已生效承诺。
