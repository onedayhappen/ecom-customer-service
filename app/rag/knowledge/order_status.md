# 订单状态说明

订单主状态、包裹状态、售后状态和资金状态分别记录，应结合查询结果解释。

## 订单主状态

| 状态 | 含义与注意事项 |
|---|---|
| 待付款 | 已创建订单，尚待核实付款；付款截止时间以订单记录为准。 |
| 已付款待发货 | 已记录付款；不能据此承诺固定发货时间。 |
| 待收货 | 包含备货及发货阶段，是否实际发货需查看原始包裹。 |
| 已收货 | 已记录订单收货状态；单个包裹签收不等于整单收货。 |
| 售后中 | 存在待审核、已批准或处理中的售后，可能只涉及部分商品。 |
| 已取消 | 取消流程已形成对应结果，退款状态仍需单独核实。 |
| 已关闭 | 订单已关闭，例如符合条件的待付款订单到期关闭。 |

## 售后结束后的订单

普通售后结束后可恢复进入售后前的订单状态；已付款取消订单的完成流程会将订单更新为已取消。不能将所有售后完成都解释为恢复原状态、整单退款或订单关闭。

## 时限与收货

当前没有统一的发货后 15 天或 30 天自动确认收货规则，也没有全品类统一的 48 小时发货承诺。退换修期限以购买商品、签收记录和适用业务规则核实，不由订单状态名称推断。
