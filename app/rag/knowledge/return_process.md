# 退货退款流程

申请资格、退回要求及退款金额以具体商品、订单和有效规则为准。演示处理与真实业务需区分。

## 申请与审核

在聊天中明确订单商品、数量、退货方式和原因；需要图片时上传实际凭证。原因和图片是待核实材料，不等于质量认定。当前支持静态图片，不支持上传视频。

核对确认卡后提交申请，再查询审核结果。没有统一的 1～2 小时审核、短信通知或 48 小时退款承诺。

## 取得授权后寄回

取得有效退货授权后，按已核实的地址、期限、商品范围和承运商要求寄回，不使用客服推测的地址。提交真实承运商与运单号，并核对寄回商品数量。

登记运单不代表快递已经揽收；物流退回、商家收货和验货结果分别查询。当前未接通上门取件及运费险赔付办理。

## 退款与费用

验货通过后的退款仍需渠道处理和结果核实。退款金额按实际购买行、数量、已支付及已退款占用计算，不保证商品标价全额退款。

退回运费、原订单运费是否退还和额外补偿分别核实，不能根据退货原因自动承诺买家或商家承担全部费用。模拟流程中的退款不代表真实资金到账。
